7. GUÍA PASO A PASO: USO DE BASE DE DATOS LOCAL VS NEON
------------------------------------------------------------------------
Gracias a la configuración dinámica implementada, cambiar entre la base de
datos local (SQLite) y la base de datos en la nube (Neon / PostgreSQL) es
extremadamente rápido y sencillo. 

El backend detecta automáticamente si las variables de entorno de PostgreSQL
están activas en tu archivo 'backend/.env'. Si no lo están, usa SQLite.

>>> PASO A PASO PARA USAR LA BASE DE DATOS LOCAL (SQLite)
1. Abre el archivo 'backend/.env'.
2. Asegúrate de que las variables de base de datos estén comentadas con '#'
   o simplemente no existan. Ejemplo:
   # DB_ENGINE=django.db.backends.postgresql
   # DB_NAME=neondb
   # DB_USER=neondb_owner
   # DB_PASSWORD=tu_password
   # DB_HOST=tu_host_neon.neon.tech
   # DB_PORT=5432
3. Guarda el archivo.
4. Ejecuta '.\run_vialtros.bat' en la raíz.
5. Django usará automáticamente el archivo local 'backend/db.sqlite3'.

>>> PASO A PASO PARA CONECTAR A LA BASE DE DATOS NEON (PostgreSQL)
1. Obtén tus credenciales desde tu consola de Neon (neon.tech).
2. Abre el archivo 'backend/.env'.
3. Descomenta y rellena las variables con tus datos de Neon. Ejemplo:
   DB_ENGINE=django.db.backends.postgresql
   DB_NAME=neondb
   DB_USER=neondb_owner
   DB_PASSWORD=npg_xD5aF7juWrHc
   DB_HOST=ep-lucky-poetry-ap6otfso-pooler.c-7.us-east-1.aws.neon.tech
   DB_PORT=5432
4. Guarda el archivo.
5. Ejecuta '.\run_vialtros.bat' en la raíz.
6. El script iniciará el servidor y aplicará automáticamente todas las
   migraciones necesarias directamente en tu base de datos remota de Neon.

>>> TRUCO PARA CAMBIO VELOZ (5 SEGUNDOS)
Dado que el backend evalúa si existe 'DB_HOST', puedes alternar entre ambas bases
de datos comentando/descomentando una sola línea en 'backend/.env':
- Para usar Neon: Deja 'DB_HOST=...' activo.
- Para usar SQLite local: Añade un '#' al principio de la línea de 'DB_HOST'.
  Ejemplo: '# DB_HOST=ep-lucky...'
