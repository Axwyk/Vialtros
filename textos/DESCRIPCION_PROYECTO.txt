¿QUÉ ES VIALTROS?
================================================================================

Vialtros es una plataforma SaaS (Software as a Service) moderna de gestión de 
rutas de transporte con seguimiento GPS en tiempo real. Es un sistema completo 
que permite a empresas de transporte administrar sus rutas, conductores, 
pasajeros y realizar rastreo en vivo de ubicaciones.

La plataforma está diseñada con roles diferenciados (Administrador, Conductor, 
Pasajero) y proporciona un panel administrativo profesional con estadísticas, 
gráficos y CRUD completo de recursos.


¿PARA QUÉ SIRVE?
================================================================================

Vialtros resuelve los siguientes problemas en la gestión de transporte:

1. ADMINISTRACIÓN CENTRALIZADA
   - Crear y gestionar rutas de transporte
   - Asignar conductores a rutas
   - Registrar pasajeros en el sistema
   - CRUD completo de usuarios y perfiles

2. SEGUIMIENTO EN TIEMPO REAL
   - Rastrear ubicación GPS de conductores
   - Actualización en tiempo real mediante WebSocket
   - Visualización de posiciones en mapas interactivos
   - Historial de recorridos

3. CONTROL DE PASAJEROS
   - Registrar estado de recogida (recogido/no recogido)
   - Asignar múltiples pasajeros a una ruta
   - Ver datos de conductores y rutas en tiempo real
   - Notificaciones de cambios de estado

4. AUTENTICACIÓN Y SEGURIDAD
   - Sistema de autenticación JWT (JSON Web Tokens)
   - Roles diferenciados con permisos específicos
   - Protección de rutas con autenticación
   - Datos encriptados y seguros

5. ANÁLISIS Y ESTADÍSTICAS
   - Dashboard con métricas de uso
   - Gráficos de actividad y rutas
   - Estadísticas de conductores y pasajeros

🔐 AUTENTICACIÓN Y SEGURIDAD
================================================================================

FLUJO DE AUTENTICACIÓN:
  1. Usuario envía credenciales (usuario/contraseña) a POST /api/token/
  2. Backend valida las credenciales
  3. Devuelve access_token y refresh_token (JWT)
  4. Frontend almacena tokens en localStorage
  5. Cada request REST incluye: Authorization: Bearer <access_token>
  6. Al iniciar la app, valida el token con GET /api/users/me/
  7. Si el token ha expirado, usa refresh_token para obtener uno nuevo

SEGURIDAD:
  - Contraseñas hasheadas con algoritmo PBKDF2
  - Tokens JWT con firma digital
  - CORS configurado para aceptar solo frontend autorizado
  - Permisos validados en backend (no solo en frontend)
  - Protección contra ataques CSRF
  - Variables de entorno para credenciales sensibles


📡 COMUNICACIÓN EN TIEMPO REAL (WebSocket)
================================================================================

El sistema usa WebSocket para actualizar ubicaciones GPS en tiempo real sin 
necesidad de hacer polling constante.

CONEXIÓN:
  URL: ws://localhost:8000/ws/tracking/<route_id>/
  Se abre cuando el usuario entra en TrackingPage

FLUJO DE DATOS:
  1. Frontend abre conexión WebSocket a una ruta específica
  2. Django Channels recibe la conexión en TrackingConsumer
  3. Conductor envia su ubicación: {latitude, longitude, status}
  4. Backend retransmite a todos los clientes conectados a esa ruta
  5. Frontend actualiza el mapa Leaflet en tiempo real

VENTAJAS:
  - Actualizaciones instantáneas sin latencia
  - Reduce carga del servidor vs polling
  - Experiencia de usuario mejorada
  - Rastreo fluido y natural

🚀 FLUJOS PRINCIPALES
================================================================================

FLUJO DE LOGIN:
1. Usuario accede a /login
2. Ingresa credenciales
3. Frontend envía POST /api/token/
4. Backend devuelve access_token y refresh_token
5. Frontend almacena tokens en localStorage
6. Se valida el rol del usuario
7. Se redirige a la página correspondiente según rol:
   - Admin → /admin/dashboard
   - Driver → /driver/routes
   - User → /user/routes

FLUJO DE RASTREO GPS EN TIEMPO REAL:
1. Admin/Conductor/Pasajero accede a página de rastreo
2. Frontend abre conexión WebSocket
3. Conductor comparte su ubicación
4. Backend recibe y transmite a todos conectados
5. Frontend actualiza mapa instantáneamente
6. Sin retrasos ni polling

FLUJO DE GESTIÓN DE RUTAS (Admin):
1. Admin va a /admin/routes
2. Ve lista de rutas existentes
3. Puede crear nueva ruta:
   - Ingresa nombre, origen, destino
   - Asigna conductor
   - Asigna pasajeros
   - Guarda
4. Puede editar ruta:
   - Modifica información
   - Cambia asignaciones
   - Guarda cambios
5. Puede eliminar ruta (con confirmación)
6. Puede rastrear ruta en tiempo real

FLUJO DE CREACIÓN DE USUARIO:
1. Admin va a /admin/users
2. Hace click en "Crear usuario"
3. Completa formulario:
   - Username
   - Email
   - Contraseña
   - Rol (admin/driver/user)
   - Estado (activo/inactivo)
4. Envía formulario
5. Backend valida y crea usuario
6. Frontend muestra confirmación
7. Usuario aparece en tabla

🔒 SEGURIDAD Y PERMISOS
================================================================================

VERIFICACIÓN DE PERMISOS:

Frontend:
- PrivateRoute valida que haya token
- Verifica el rol del usuario
- Solo muestra opciones permitidas
- Oculta páginas no autorizadas

Backend:
- Cada endpoint valida el token JWT
- Cada ViewSet verifica permisos del usuario
- Solo devuelve datos que el usuario puede ver
- Registra acciones para auditoría

PROTECCIÓN DE DATOS:
- Contraseñas hasheadas
- Tokens con expiración
- CORS restringido
- Validación de entrada en backend
- SQL injection prevención (ORM de Django)
- XSS prevention (escape de datos)
